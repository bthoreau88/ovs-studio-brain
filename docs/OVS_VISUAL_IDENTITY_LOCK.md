# OVS Studio Brain Visual Identity Lock

Status: active and required.

## Core Principle

OVS Studio Brain is an editorial operating instrument. It should read like a working studio index designed through the same visual intelligence as an OVS poster, book jacket, dossier, or one-sheet. It must not resemble a generic dark-mode SaaS admin template.

## Composition

- Build with strong verticals, open ivory space, black fields, thin rules, and asymmetrical column balance.
- Treat page titles as editorial display matter, not ordinary dashboard headings.
- Use numbered navigation, folios, indexes, and explicit section boundaries.
- Use black bands selectively for primary project focus and brand lockups.
- Keep operational information dense but typographically calm.

## Color

- Paper: `#F1EFE9`
- Ink: `#090909`
- Secondary paper: `#E4E1DA`
- Muted metadata: `#706D67`
- OVS system cipher: `#00FF87`, used sparingly for active indexes and system state
- Destructive warning: `#8F211D`

No gold, olive, purple, blue, neon, glow, glass, or decorative gradient treatment is part of this lock.

## Logo

Approved file: `assets/logos/ovs_umbrella_primary.png`

The umbrella-skull mark and Omnia Vanitas Studios wordmark must remain intact. No generated approximation is permitted.

## Interface Geometry

- Default radius: `0`
- Default shadow: none
- Section separation: one-pixel black or neutral rules
- Primary command: black rectangle with ivory text
- Secondary command: outlined rectangle
- Cards: avoid; use full-width bands, lists, tables, and open panels

## Typography

- Display: Didot, Bodoni 72, Bodoni MT, Times New Roman fallback
- Interface: Helvetica Neue, Helvetica, Arial fallback
- Tracking remains at the browser default; hierarchy comes from scale, weight, case, and space.
