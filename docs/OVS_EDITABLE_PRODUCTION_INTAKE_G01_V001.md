# OVS-PROD-EDIT-G01 V001 — Editable Production Intake + Router

Use this intake before selecting a production workflow.

## Required questions
1. **Goal:** What are we making or fixing? State the production problem, not only the desired aesthetic.
2. **Source assets and project files:** Provide original video/audio/stills/3D/graphics and any existing .blend, .prproj, .aep, .ai, .psd, .toe/.tox, Resolve project/archive, XML/AAF/EDL, or other source projects.
3. **Authority labels:** Which assets are source authority, approved OVS canon/identity authority, lighting/editorial/motion reference, or loose inspiration?
4. **Preferred tools:** Which applications should be preferred or avoided?
5. **Local availability:** Which required desktop applications/runtimes are actually installed and usable?
6. **Output contract:** Resolution, aspect ratio, fps, codec/container, color space, audio format, and required editable native project files.
7. **Duration/scope:** Total runtime, shot count, scene count, or deliverable count.

## Router
- Spatial 3D / camera / environment / simulation -> Blender family.
- Editorial organization / proxies / sequence construction -> Premiere Pro.
- Layered shot build / VFX / cleanup / motion graphics -> After Effects.
- Vector source reconstruction -> Illustrator.
- Still-image non-destructive repair -> Photoshop.
- Interactive or live/reactive system -> TouchDesigner.
- Conform / shot match / finishing color / delivery -> DaVinci Resolve Studio.

Use only the tools needed. When a second application is proposed, state exactly what authority moves with the handoff and what the receiving app may change.

## Setup check
Before editing, load the matching setup instruction for Blender, Premiere, After Effects, Illustrator, or Photoshop. For TouchDesigner and Resolve, inspect the available workflow instructions before mutation.

## Source law
The workflow bundle banner, command tile, UI screenshot, generated preview, or marketing image is not source artwork. References control only their assigned qualities.

## Exit
A workflow is selected only after the source files, authority map, local tool availability, output contract, and duration are known or explicitly marked HOLD.
