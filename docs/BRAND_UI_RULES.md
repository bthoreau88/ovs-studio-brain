# OVS Studio Brain Brand UI Rules

## Strict Logo Identity

- The only approved primary mark is `assets/logos/ovs_umbrella_primary.png`.
- The asset includes the official umbrella-skull, O/S monogram, and Omnia Vanitas Studios wordmark.
- Never redraw, simplify, rotate, crop, recolor, trace, or generate a substitute mark.
- Keep clear space around the complete lockup. It is a brand asset, not interface decoration.

## Visual DNA

- Editorial poster composition rather than conventional SaaS dashboard styling.
- Ivory paper and absolute black are the dominant surfaces. Emerald is the single system cipher; red is reserved for destructive warnings.
- Use severe scale contrast: oversized display typography beside compact operational metadata.
- Prefer hairline rules, open sections, numbered folios, tables, and bands over rounded cards.
- Use Didot/Bodoni-style serif typography for display and editorial content.
- Use Helvetica-style sans serif typography for controls, metadata, and navigation.
- Use square buttons and fields. Radius, glow, glass, gradients, ornamental shadows, and colored dashboard cards are prohibited.
- Layouts should feel asymmetrical but precise, with visible grid logic and disciplined negative space.
